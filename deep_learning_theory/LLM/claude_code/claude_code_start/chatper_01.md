## 1.4 왜 클로드 코드인가?
- 터미널 에이전트 카테고리 : 클로드 코드, 제미나이 CLI, OpenAI 코덱스
  - 에이전틱 방식 : 자연어 명령을 받아 코드를 수정하고 테스트를 실행
 
- 제미나이 CLI
  - 구글이 만든 오픈소스 터미널 에이전트
  - 강점
    - 넉넉한 무료 사용량(일 1000 요청)
    - 100만 토큰 컨텍스트 윈도우
      - 비용 부담 없이 터미널 에이전트 경험 시 좋은 출발점
    - 구글 서치가 내장되어 있음
      - 최신 정보를 참조하면서 작업할 수 있음
- Open AI 코덱스
  - 오픈소스로 공개된 터미널 에이전트
  - 특징
    - 서브에이전트를 활용한 병렬 실행과 클라우드 샌드박스

- 클로드 코드를 선택한 데 세 가지 구체적인 이유
  - (1) 복잡한 실전 작업에서의 코드 품질
    - 단순한 함수 하나를 생성하는 수준에서 => 세 도구의 차이가 크지 않음
    - 차이가 드러나는 것 : 여러 파일에 걸친 리팩터링, 비즈니스 로직 구현, 기존 코드와 일관성 유지처럼 맥락을 깊이 이해해야 하는 작업
      - 강점 : 다중 파일에 걸친 변경의 일관성

  - (2) 개발 워크플로 전체를 커버함
